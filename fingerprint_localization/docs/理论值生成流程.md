# 理论值生成流程

### Step 1：整理每个采样点的数据

每个点整理一张表：

```Plain Text
point_id
corridor_id
state = LOS / OLOS / NLOS
distance_to_gateway
mean_RSSI
var_RSSI
mean_SNR
chirp_available = 1/0
rho_chirp
tau_rms_chirp
tau_d
```

其中：

- `mean_RSSI`、`var_RSSI`、`mean_SNR` 从 LoRa 数据包统计；

- `distance_to_gateway` 用你已经算好的距离表；

- `state` 先按走廊和RSSI突变粗分；

- `chirp_available`：

    - 走廊0/1 可测为 1；

    - 走廊2 chirp 收不到为 0；

- `rho_chirp` 只在 chirp 可测点计算；

- `tau_rms_chirp` 只在 chirp 可测点计算；

- `tau_d` 是最终加入模型的时延扩散分量。

---

### Step 2：从 chirp 数据计算 $\rho$ 和 $\tau_d$

对每个有 chirp 的点，计算主峰能量占比：

$\rho=\frac{\text{主峰窗口能量}}{\text{PDP总能量}}$

操作方式：

```Plain Text
1. chirp 匹配滤波得到 PDP
2. 找最大峰
3. 最大峰附近取一个小窗口，作为主峰能量
4. 主峰能量 / PDP总能量 = rho_chirp
```

同时计算 RMS delay spread：

$\bar{\tau} = \frac{\sum_{\tau}\tau P(\tau)}{\sum_{\tau}P(\tau)}$

$\tau_{\text{rms}} = \sqrt{
\frac{\sum_{\tau}(\tau-\bar{\tau})^2P(\tau)}{\sum_{\tau}P(\tau)}
}$

第一版直接令：

$\tau_d = \tau_{\text{rms}}$

不要一开始做复杂换算。

走廊2没有 chirp，不计算 $\rho_{\text{chirp}}$ 和 $\tau_{\text{rms}}$，直接认为：

```Plain Text
NLOS: rho ≈ 0
NLOS: tau_d 取 OLOS 区 tau_d 的较高分位数，例如 75% 或 90% 分位
```

---

### Step 3：从 S17 估计每个 LoRa 包的 $\rho$

不要用完整 17 维向量，只提两个量。

对每个 LoRa 包的 16 个 preamble 符号，取 dechirp \+ FFT 后的 17 bin。

#### 1\. 主 bin 集中度

$C_S=\frac{\text{bin0能量}}{17\text{个bin总能量}}$

#### 2\. bin0 幅度抖动

$J_S=\frac{16\text{个preamble中bin0能量标准差}}{16\text{个preamble中bin0能量均值}}$

直觉：

```Plain Text
C_S 越大 → 主径越强 → rho 越大
J_S 越大 → 主径越不稳定 → rho 越小
```

然后用一个很简单的模型估计：

$\hat{\rho}=\text{sigmoid}(a_0+a_1C_S-a_2J_S)$

用 chirp 可测点训练这个模型：

```Plain Text
输入：C_S, J_S
标签：rho_chirp
```

走廊2 NLOS 点加入约束：

```Plain Text
rho_hat 不应太高
```

第一版甚至可以更简单：

```Plain Text
LOS/OLOS 用 C_S 和 J_S 估计 rho
NLOS 直接设 rho = 0
```

---

### Step 4：估计每个点的 $\tau_d$

#### chirp 可测点

直接使用：

$\tau_d = \tau_{\text{rms}}$

也就是从 chirp PDP 算出来的 RMS delay spread。

#### 非 chirp 点

不要从 S17 强行恢复 $\tau_d$。

用状态和距离做一个简单估计：

```Plain Text
LOS：使用附近 LOS chirp 点的 tau_d 均值或插值
OLOS：使用附近 OLOS chirp 点的 tau_d 均值或插值
NLOS：使用 OLOS tau_d 的高分位数，例如 75% 或 90% 分位
```

如果要写成公式，可以用：

$\log \tau_d = b_0 + b_1\log d + b_2 I_{\text{OLOS}}$

先只在 chirp 可测的 LOS/OLOS 点上拟合。

NLOS 暂时不拟合，直接设为较大的 diffuse tail 先验。

---

### Step 5：生成粗物理指纹 $(x_{\text{phy}})$

每个点生成一个粗物理 RSSI\+ 向量。

假设你的 RSSI\+ 是：

```Plain Text
[SNR, mean_RSSI, median_RSSI, mode_RSSI, var_RSSI, RSSI_residual]
```

那么构造：

```Plain Text
mean_RSSI_phy = 该点路径损耗模型预测值
median_RSSI_phy = mean_RSSI_phy
mode_RSSI_phy = mean_RSSI_phy
var_RSSI_phy = s0 + s1 * (1 - rho^2) + s2 * log(1 + tau_d / tau_ref)
SNR_phy = q0 + q1 * mean_RSSI_phy
RSSI_residual_phy = 0
```

也就是：

$x_{\text{phy}} = [\text{SNR}_{\text{phy}}, \mu_{\text{phy}}, \mu_{\text{phy}}, \mu_{\text{phy}}, \sigma^2_{\text{phy}}, 0]$

这里最重要的是：

$\sigma^2_{\text{phy}} = s_0 + s_1(1-\rho^2) + s_2\log\left(1+\frac{\tau_d}{\tau_{\text{ref}}}\right)$

意思是：

```Plain Text
rho 高 → 主径稳定 → RSSI 方差小
rho 低 → 漫射/NLOS强 → RSSI 方差大
tau_d 大 → 时延扩散强 → RSSI 方差进一步增大
```

其中：

$\tau_{\text{ref}}$

取所有 chirp 可测点 $\tau_d$ 的中位数。

---

### Step 6：计算真实残差

每个真实 LoRa 样本都有真实 RSSI\+：

$x_R$

计算：

$r = x_R - x_{\text{phy}}$

保存训练数据：

```Plain Text
residual = x_R - x_phy
condition = [point_id, rho, tau_d, state]
```

---

### Step 7：训练 DDPM 学残差

DDPM 不再直接生成完整 RSSI\+，而是生成残差：

$p_\theta(r \mid \text{point}, \rho, \tau_d, \text{state})$

训练输入：

```Plain Text
输入数据：residual
条件：point_id, rho, tau_d, state
输出：生成 residual
```

生成时：

$\hat{x}_R = x_{\text{phy}} + \hat{r}$

这一步就是本文核心：

```Plain Text
随机多径模型生成粗物理指纹
DDPM 学真实数据和物理模型之间的差异
```

---

### Step 8：用增强指纹训练定位器

对每个点生成若干增强 RSSI\+ 样本：

```Plain Text
x_aug = x_phy + DDPM_generated_residual
```

然后用：

```Plain Text
真实 RSSI+ + 增强 RSSI+
```

训练定位器。

定位器仍然输出：

$P(l \mid x_R)$

即 54 个参考点的后验分布。

## 最关键的验证

```Plain Text
1. 用 C_S 和 J_S 估计出来的 rho_hat，
   是否和 chirp 计算的 rho_chirp 有相关性。

2. 加入 tau_d 后，
   x_phy + DDPM residual 是否比只用 rho 的版本定位更准。
```

如果第 1 个成立，就说明 S17 对主径占比有用。

如果第 2 个成立，就说明时延扩散分量确实带来增益。

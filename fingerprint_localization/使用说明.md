## 1. 目录格式说明

**config** 中包含训练和模型的参数

**model/v1/input** 中保存 RSSI指纹生成模型的训练和测试数据

**model/v1/output** 中保存 DDPM**噪声预测模型**的二进制文件和模型输出的**生成指纹**，注意**不可删除output文件夹中的location_vector_v2.csv文件**

**model/v1/RGM** 中保存 模型的**训练和测试脚本**，src文件目录下包含vae、DDPM的实现代码



## 2. 代码运行

### 环境配置

为了保证程序的顺利运行，事先进行环境的安装，在项目根目录运行以下指令：

```
conda env create -f environment.yml
```

如果出现安装崩溃的情况，可根据控制台打印信息单独使用pip install对所需的每个库进行安装。

环境配置完成后即可进行实验，实验大体上分为**指纹生成和指纹训练定位器**两个部分

### 指纹生成

#### 非跨域生成

* 在model/v1/RGM目录中，运行1_pretrain_rgm.py脚本，其中训练参数在configs\pretrain.yml中进行修改：

  ```
  data_name: "floor3_sf_11_pretrain_dataset.pth"
  ```

  即可指定训练数据集，其他参数已经过调优无需再做调整。

* 在model/v1/RGM目录中，运行3_generate_database.py脚本，其中训练参数在configs\finetune.yml中进行修改：

  ```
  data_name_ft: "floor3_sf_11_test_dataset.pth"  
  data_name_fake: "floor3_sf_11_area_fake_rgm.pth" 
  ```

  data_name_ft表示后续定位器使用的验证数据集（**注：这里只填写带有test字样的数据集**），为了验证我们生成数据的一个有效性和真实性，在定位阶段需要使用真实数据进行测试。data_name_fake表示生成的数据集文件名，在generate过程中其也包含了data_name_ft。

* 在model/v1/RGM目录中，运行classifier_finger.py脚本，

  ```
  input_dim=8	#等于数据集中特征长度+2（即pretrain或者finetune yaml文件中的input_dim+2)
  mode='generate'
  ```

  脚本顶部的若干行为定位器的参数配置，只需修改输入维度和mode即可，mode='generate'代表使用生成数据进行训练。



#### 跨域生成

* 在model/v1/RGM目录中，运行1_pretrain_rgm.py脚本，其中训练参数在configs\pretrain.yml中进行修改：

  ```
  data_name: "floor3_sf_11_pretrain_dataset.pth"
  ```

  即可指定训练数据集，其他参数已经过调优无需再做调整。

* 在model/v1/RGM目录中，运行2_finetune_rgm.py脚本，其中训练参数在configs\finetune.yml中进行修改：

  ```
  data_name: "floor4_sf_11_finetune_dataset.pth" 
  ratios_locs: 1  
  ```

  注意，跨域的选择（sf或者floor）取决于该配置中的data_name，**文件名中带有finetune字样的均为微调阶段所用数据集**，如果想跨sf生成则选择文件名中与预训练阶段不同的sf，跨楼层同理。

* 在model/v1/RGM目录中，运行3_generate_database.py脚本，其中训练参数在configs\finetune.yml中进行修改：

  ```
  data_name_ft: "floor4_sf_11_finetune_dataset.pth"  
  data_name_fake: "floor4_sf_11_area_fake_rgm.pth" 
  ```

  注意，data_name_ft的选择应该和finetune过程中data_name**所属的“域”是一样的**！
